
# Student Management System

A simple student management application built with Python and JSON.

## Features
- Add new students
- View all students
- Search students by ID
- Save student records in JSON
- Prevent duplicate student IDs

## Requirements
- Python 3

## How to Run

```bash
python student_management.py
```

## Files
- `student_management.py` - Main Python program
- `students.json` - Student data, created automatically

## Technologies
- Python
- JSON

## Purpose
This project is designed for beginners to practice
Python functions, lists, dictionaries, loops, and file handling.
